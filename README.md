# WordPress 業種別サンプルサイト集

WordPressで使える業種別のサンプルデータ集です。
WXR（WordPress eXtended RSS）形式なので、管理画面からインポートするだけで使えます。

## 対応業種

| 業種 | ステータス | 説明 |
|------|-----------|------|
| クリニック・医院 | ✅ 対応済 | 内科・小児科などの医療機関向け |
| 建設業 | 🚧 準備中 | 工務店・建設会社向け |
| 飲食店 | 🚧 準備中 | レストラン・カフェ向け |
| 美容院・サロン | 🚧 準備中 | ヘアサロン・エステ向け |
| 法律事務所 | 🚧 準備中 | 弁護士・士業向け |
| 不動産 | 🚧 準備中 | 不動産会社向け |

## 使い方

1. 使いたい業種のフォルダから `.xml` ファイルをダウンロード
2. WordPress管理画面で `ツール` → `インポート` を開く
3. 「WordPress」を選択（初回はインポーターのインストールが必要）
4. ダウンロードした `.xml` ファイルを選択してインポート

## ディレクトリ構成

```
wp-industry-samples/
├── clinic/                 # クリニック・医院
│   ├── clinic-sample.xml   # WXRインポートファイル
│   ├── pages/              # 固定ページの元データ
│   ├── posts/              # 投稿の元データ
│   └── assets/             # 画像などのアセット情報
├── construction/           # 建設業（準備中）
├── restaurant/             # 飲食店（準備中）
└── shared/                 # 共通アセット
```

## 含まれるコンテンツ

### クリニック・医院
- **固定ページ**: トップ、診療案内、医師紹介、アクセス、初診の方へ、お問い合わせ、料金表、FAQ
- **投稿**: お知らせ、休診情報、健康コラム
- **その他**: メニュー構成、診療カレンダー用データ
